# 光影相册 · Photo Album

一个美观、易用的纯前端相册管理平台。所有数据保存在浏览器本地（IndexedDB），无需安装任何后端服务。

## 🚀 快速开始

### 方式一：直接打开（最简单）

1. 找到项目目录下的 `index.html` 文件
2. 双击它，默认浏览器会自动打开应用
3. 🎉 开始使用！

### 方式二：使用本地服务器（推荐，避免某些浏览器限制）

如果直接双击有问题，可以用 Python 启动一个简易服务器：

```bash
# 进入项目目录
cd photo-album

# Python 3
python -m http.server 8000

# 然后在浏览器访问
# http://localhost:8000
```

或者使用 Node.js：

```bash
npx serve .
```

## ✨ 功能特性

### 核心功能
- 📷 **照片上传** - 支持拖拽和点击上传，自动压缩大图
- 🏷️ **标签管理** - 自定义标签和颜色，灵活分类
- 📝 **描述编辑** - 为每张照片添加详细说明
- 🔍 **多维搜索** - 按标签、日期、描述、文件名搜索
- ❤️ **收藏功能** - 标记喜欢的照片
- 📅 **日期管理** - 自定义拍摄日期
- 🎨 **视图切换** - 网格视图 / 瀑布流视图
- 💾 **数据导出** - 一键导出所有数据为 JSON
- ⌨️ **键盘导航** - 灯箱模式支持方向键切换

### 视觉设计
- 🌑 现代化深色主题，护眼舒适
- 🎨 渐变色设计语言，精致细节
- ✨ 流畅的过渡动画
- 📱 响应式布局，适配各种屏幕

## 🎯 使用指南

### 上传照片
点击左上角"上传照片"按钮，支持：
- 点击选择文件
- 拖拽文件到上传区域
- 一次选择多张

### 管理标签
- 点击侧边栏标签旁的 **+** 按钮新建标签
- 选择喜欢的颜色，让标签更具辨识度
- 点击标签可筛选该标签下的所有照片
- 悬停标签可看到删除按钮

### 编辑照片
1. 悬停照片，出现操作按钮
2. 点击编辑按钮 ✏️
3. 修改日期、描述、标签
4. 点击保存

### 搜索
顶部搜索框支持搜索：
- **标签名称** - 例如输入"旅行"
- **描述内容** - 例如输入"日落"
- **拍摄日期** - 例如输入"2024-08"
- **文件名** - 例如输入"DSC"

### 灯箱浏览
- 单击任意照片进入全屏浏览模式
- 使用 `←` `→` 方向键切换
- 按 `Esc` 退出

## 💾 数据存储

所有数据存储在浏览器的 IndexedDB 中，**不会上传到任何服务器**。首次打开应用时会自动生成 10 张示例照片以供体验，你可以删除它们并上传自己的照片。

数据导出功能可以备份你的所有照片和标签。

## 🌐 浏览器兼容性

支持所有现代浏览器：
- Chrome / Edge 90+
- Firefox 88+
- Safari 14+
